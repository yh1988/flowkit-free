# 安装与导入指南（10 分钟跑通）

## 一、准备 n8n（三选一）

**方式 A：本机试跑（最快，无需 Docker）**

```bash
# 需要 Node.js 20+（推荐 22/24）
mkdir n8n-demo && cd n8n-demo
npm init -y && npm i n8n
npx n8n
```

浏览器打开 http://localhost:5678 ，首次会让你创建管理员账号（邮箱+密码，本地数据不出机器）。

**方式 B：Docker（推荐正式使用）**

```bash
docker volume create n8n_data
docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

**方式 C：云服务器**

任意 1 核 1G 起的 VPS 均可（阿里云/腾讯云轻量 ≈ ¥30-60/月）。如果后面要接 Webhook 回调（比如工作流 03），建议顺手配一个域名 + HTTPS（Caddy 一行配置）。

## 二、导入工作流（两种方法）

**方法 1：界面导入（推荐新手）**

n8n 界面左上角 `Workflows → ⋯ → Import from file`，选择 JSON 文件即可。一次导一个。

**方法 2：命令行批量导入**

```bash
# 在 n8n 已安装的机器上执行（先停掉正在运行的 n8n）
npx n8n import:workflow --separate --input=workflows
```

## 三、配置

这 3 个工作流**零配置**，导入即可跑通：

1. **01 · RSS 科技日报**：打开后点 `Execute workflow`，跑完在「写入文件」节点指向的 `output/` 目录里拿到日报 HTML。
2. **02 · 网页变化监控**：第一次运行是记录基线，第二次起才有比对结果（这是正常逻辑，不是 bug）。
3. **03 · Webhook 线索收集**：激活（右上角 Active）后，向工作流里标注的 Webhook URL POST 一条 JSON 即可看到落表。

## 四、常见问题

- **JSON 导入后节点显示红色/过时？** 一般是 n8n 版本差异，双击节点确认参数还在、点开看一眼即可，不影响执行。
- **定时任务没跑？** 工作流右上角开关要置为 **Active**；Self-hosted 的 Schedule Trigger 依赖进程常驻。
- **写文件去了哪里？** 相对路径 `output/` 是相对 n8n 进程的启动目录；不确定就用绝对路径（如 `D:/data/output/xx.csv`）。
- **写文件报 "Access to the file is not allowed"？** Self-hosted 默认只允许写 `~/.n8n-files`。设置环境变量后重启 n8n：`N8N_RESTRICT_FILE_ACCESS_TO="D:/你的目录;D:/另一个目录"`（**多个路径用分号分隔**）。
- **写文件报 "The file or directory does not exist"？** 先手动创建目标目录（n8n 不会自动建目录），或把路径改成已存在的目录。
